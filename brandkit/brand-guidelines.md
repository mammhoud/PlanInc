# PlanInc Brand Guidelines

## Brand Identity

- **Product**: PlanInc — Enterprise Planning & Incubation Platform
- **Tagline**: "From idea to orbit."
- **Category**: Developer planning & incubation tool
- **Audience**: Technical founders, indie builders, engineering teams
- **Personality**: Precise · minimal · path-driven · architectural · focused

## Logo Usage

| Variant | Usage |
|---|---|
| `planinc-mark.svg` | App icon, favicon, loading screen |
| `planinc-wordmark.svg` | README, documentation headers |
| `planinc-lockup-h.svg` | Main app header |
| `planinc-lockup-v.svg` | Documentation covers |
| `planinc-mark-white.svg` | Dark overlays |

## Color System

| Token | Value | Usage |
|---|---|---|
| `--planinc-bg` | `#0d0d0f` | App background |
| `--planinc-surface` | `#1e1f26` | Card/panel surfaces |
| `--planinc-border` | `#2d2f3d` | Dividers, borders |
| `--planinc-accent` | `#f59e0b` | Primary interactive, brand accent |
| `--planinc-accent-hover` | `#fbbf24` | Hover state |
| `--planinc-text` | `#f8fafc` | Primary text |
| `--planinc-text-muted` | `#94a3b8` | Secondary text |
| `--planinc-ghost` | `#334155` | Disabled states |

## Typography

| Role | Font | Weight |
