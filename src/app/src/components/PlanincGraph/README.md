# `src/app/src/components/PlanincGraph`

Interactive graph surface for PlanInc planning entities.

## Interaction model

- D3 force simulation positions nodes and keeps collisions readable.
- D3 zoom provides pan and wheel/pinch zoom.
- D3 drag lets users reposition nodes temporarily.
- React owns selection, keyboard navigation, and preview state.
- Sky-blue semantic colors keep the graph aligned with the PlanInc brand.
